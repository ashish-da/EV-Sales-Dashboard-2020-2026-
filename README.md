# 🚗 EV Sales Dashboard (2020–2026)

## 📌 Project Overview

This Power BI dashboard analyzes global Electric Vehicle (EV) sales between **2020 and 2026**. It provides business insights into market performance, vehicle specifications, regional sales, brand performance, and market segmentation using interactive dashboards.

# 📈 Key Business Insights

- Total EV sales reached **$20.22T**, achieving **96%** of the target.
- Tesla dominates global EV sales.
- Luxury vehicles generate the highest sales.
- Premium variants account for the largest market share.
- Vehicles with **5-year warranties** generate the highest revenue.
- Model Y is the top-selling EV model.
- AWD is the most popular drivetrain.
